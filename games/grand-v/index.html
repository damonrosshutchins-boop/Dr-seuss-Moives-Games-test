GTA V, served from your own PC

Grand-V is a reverse-engineered GTA V engine compiled to WebAssembly with WebGPU. Its repository ships the native launcher, not the game: the launcher reads your own GTA V files and serves them on this computer. Start it, then open it here.

A bare port means http://localhost:PORT/launcher.html. Paste a full https://…trycloudflare.com/launcher.html link to join someone else's host.

Checking for a launcher on port 8000…

  1. Get the launcher. Download $GrandV back-end host for Windows, macOS or Linux from the project releases (or build it from LauncherApp/rust).
  2. Point it at your game. Put the launcher beside your playgta5-offline folder or pick the folder in the launcher. Grand-V does not include GTA V data — use a copy you own.
  3. Start hosting. Choose This PC and press Start & open game. The default port is 8000; if you changed it, enter that port above.
  4. Open it from here. This page checks the port and hands the tab to the launcher.
Repository Launcher guide Releases
  • The engine uses WebGPU, WebAssembly memory64 and shared-memory workers. The launcher sends COOP/COEP headers so the page becomes cross-origin isolated; an iframe inside the arcade cannot, so the game needs its own top-level tab.
  • Use current Chrome or Edge on desktop with hardware acceleration. Mobile support is experimental.
  • Nothing is proxied or re-hosted: the tab talks straight to localhost on your machine.
