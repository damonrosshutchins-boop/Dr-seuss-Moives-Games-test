🏎️ WebCompiled

Mario Kart Wii browser port based on WebAssembly and WebGPU. The project's open-source files are linked to Seuss Arcade, but the GitHub repository contains no playable game build or game data.

Checking browser support…

To make this playable inside the arcade, its developer requires a host to build WebCompiled from their own unmodified PAL RMCP01 game copy. That build creates a web/dist/ folder with the compiled engine and required game data. Once that authorized build is hosted, it can be connected to a fixed approved game route.

Current status: project added, build needed. This entry does not download copyrighted game data or provide a general-purpose proxy.

WebCompiled repository and build instructions
