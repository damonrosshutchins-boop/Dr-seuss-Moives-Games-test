Why this is a setup page

The upstream project contains approximately 1 GB of split commercial game disc data and a compiled emulator. The game content cannot be republished here. A fully playable offline browser version would also need an authorized emulator/runtime build and browser isolation support. This page prepares only the local-file part of that workflow.
