Install the Blooket bot script

Once installed it runs by itself on Blooket's join page, so the bots panel joins a game with one button — no console, no paste.

  1. 1 · Add a userscript manager

    Browsers only run userscripts through a manager. Tampermonkey or Violentmonkey, installed once, is all it takes.
